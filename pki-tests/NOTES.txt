ML-KEM:
-------

Create private key:

  openssl genpkey -algorithm ML-KEM-512 -out priv.pem

Extract the public key:

  openssl genpkey -algorithm ML-KEM-512 -out priv.pem

Encapsulate a secret key (created by openssl and stored in secret.dat) into file ctext.dat:

  openssl pkeyutl -encap -inkey pub.pem -secret encap.dat -out ctext.dat

Display the byte contents of a binary file encap.dat:

  od -t x1 encap.dat 

Decapsulate the shared secret in ctext.dat, to file decap.dat:

  openssl pkeyutl -decap -inkey priv.pem -secret decap.dat < ctext.dat

Check that the key transfer worked:

  diff -s encap.dat decap.dat
