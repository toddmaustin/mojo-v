** Mojo-V Reference Platform - Release 1.1

  - Added EXO library support for program-level development of Mojo-V applications, including new and refined guidance for legal data-oblivious coding patterns.
  - Added 40 Bringup-Bench benchmark ports to broaden workload coverage for Mojo-V software bring-up and evaluation.
  - Improved benchmark naming consistency and repository organization with follow-up cleanup and maintenance integration updates.

** Mojo-V Reference Platform - Release 1.00

  - This release fully implements (in the Spike RISC-V simulator) a reference Mojo-V target with an V64GC ISA, ML-KEM-512 key encapsulation for data contract loading, and Simon-128 symmetric key encryption for secret computation encryption.
  - Updated Mojo-V specification to v1.00
  - The Key Management Shadow Map has been added, this is an internal data structure that allows programmers to i) probe the processors public key, ii) inject an ML-KEM-512 encapsulated key into the processor, and iii) inject a 3rd-party encrypted data contract into the processor. Together these facilities allow a third party to give Mojo-V hardware access to sensitive data in a way that does not permit programmers and hackers to see the sensitive data, but while allowing them to compute upon the encrypted data.
  - Most of Mojo-V's implementation in Spike is now moved to riscv/mojov-crypto.h and riscv/mojov-crypto.cc.
  - Most of Mojo-V's implementation in bringup-bench is now moved to bringup-bench/target/mojov-utils.h and bringup-bench/target/mojov-utils.c
  - Fully implemented 3rd-party decryption validation, so now when a value is decrypted, it is checked to see if the internal signature value matches the current data contract, and if not, the decryption fails.

** Mojo-V Reference Platform — Release 0.92

  - Updated Mojo-V specification to v0.92
  - Added support for Mojo-V proof-carrying computation, used to perform remote computational integrity checking.
  - Added "mojov-pctests" benchmark for performing positive and negative testing of Mojo-V's proofcarrying encryption format.
  - Expanded INT and FP secret register set size (from 4 regs) to 8 regs.
  - Fixed input and output dependency marking for a range of RV64GC instruction implementations in Spike.

** Mojo-V Reference Platform — Release 0.91

  - Update Mojo-V specification to v0.91
  - Added FP encrypted load/store, i.e., FLDE and FSDE
  - Renamed “weak” encryption mode to “fast”
  - Cleaned up Bringup-Bench directory tree
  - Added extensive security tests (380 positive + 245 negative tests == 625 total tests).
  - Added new integer and FP benchmarks, using fast and strong encryption.
  - Added RISC-V trap handling to Bringup-Bench to enable negative testing.
  - Added -fmojov-strong option to Spike to switch between fast/strong Mojo-V encryption.

** Mojo-V Reference Platform — Release 0.90

  The Mojo-V reference platform release 0.90 implements secret integer
  computation using a fixed symmetric key cipher. As of this release,
  64-bit integer secret computation is fully secretized and this early
  reference platform can be used for software development and red-teaming.
  Additional capabilities will be rolled out in future releases, including
  PKI support, secret FP register support, LLVM compiler support, 32-bit
  RISC-V support, VIP-Bench benchmarks support, etc.
